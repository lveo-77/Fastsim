# Fastsim:已知赛道,跑最快的一圈

比赛时,车第一圈边跑边建图;建完图以后,整条赛道的边界就都知道了。
这个作业模拟的就是这一步:**给你完整的赛道边界,规划一条路线和速度,让车一圈跑得越快越好。**

赛道是比赛的 A、B、C、D 四套。比赛当天随机抽一套,所以你的程序要**不改代码、四条都能跑**。

![四条赛道](docs/tracks.png)

## 你要做什么

**只改 `homework/planner.py` 里的 `plan(track, car)`**,返回:

- `path`:形状 `(n, 2)`,一圈的路线点(米),按行驶方向(逆时针)排列,首尾不用重复;
- `speed`:形状 `(n,)`,每个路线点上想要的车速(m/s)。

评分脚本用 `fastsim.PathFollower` 沿你的路线开车:用纯追踪算转角,按你的速度表给油门。

### 规则

- 车从起跑线静止出发,跑完一整圈计时;
- 车身(0.56 × 0.35 m 的矩形)任何一个角压出边界,就算出界,这条赛道不计成绩;
- 超过 120 秒没跑完算超时;
- 成绩 = 四条赛道用时之和,**四条都必须完赛**。

### 你能用的东西

| | 说明 |
|---|---|
| `track.left` / `track.right` | 左(内)、右(外)边界,闭合折线 |
| `track.centerline` | 中心线,5 cm 一个点,首点是起跑线 |
| `track.bounds()` | 中心线每点的左法向,以及到左、右边界的距离 |
| `track.on_track(points)` | 判断一批点在不在赛道上 |
| `track.length` | 一圈长度 |
| `car` (`CarParams`) | 车的参数:轴距、车身尺寸、最高速度、加减速度、横向抓地力上限等 |

车的模型在 `fastsim/car.py`,读一下就知道车能做到什么、做不到什么:

- 速度不是给多少就是多少:要花时间追上目标(`speed_tau`),加减速度也有上限;
- 转弯时横向加速度 `v² / R` 超过 `a_lat_max`,轮胎就抓不住,车往外推。

## 思路提示(由易到难)

1. **直道快、弯道慢**:算出路线每一点的弯曲程度(曲率 κ = 1/R),弯道限速 `v ≤ sqrt(a_lat / κ)`;
2. **提前刹车**:车不能瞬间减速。从弯道往回倒推,保证每一段都来得及刹下来;出弯同理,加速也要时间;
3. **别贴着极限**:模型和跟踪都有误差,给横向加速度和边界都留点余量。四条都要完赛,一次出界比慢一秒亏得多;
4. **走赛车线**:外-内-外切弯,弯道半径更大,就能过得更快。用 `track.bounds()` 在赛道宽度内移动路线点;
5. **进阶**:`PathFollower` 不够好?可以自己写控制器,见下一节。

## 注意

- 赛道坐标是从规则图估读出来的,不是实地测量,和真实赛道会有几厘米到十几厘米的出入;
- 车的参数有的是实测,有的是估计(见 `fastsim/params.py` 注释),尤其极速(5 m/s)和刹车能力还没实测。仿真里跑得快,不等于实车也敢这么跑。
