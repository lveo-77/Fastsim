# 车辆参数与物理模型

本文件是作业的统一参数说明，与 `fastsim/params.py`、`fastsim/car.py` 对应。
尺寸与转向参数参考队内实车；性能参数是教学假设，不代表实车测量结果。

## 最终标称数值

| 参数 | 最终值 | 含义 |
|---|---:|---|
| 重力加速度 g | 9.81 m/s² | 1 G = 9.81 m/s² |
| 统一摩擦系数 μ | 0.4 | 总抓地加速度上限 μg = **3.924 m/s²（0.4 G）** |
| 驱动能力上限 | **0.3 G（2.943 m/s²）** | 整车加速能力，与轮胎极限分开设置 |
| 直线最大减速度 | **0.4 G（3.924 m/s²）** | 假设四轮制动，制动能力足以用满抓地 |
| 匀速转弯侧向极限 | **0.4 G（3.924 m/s²）** | 没有纵向加减速时才可全部用于转弯 |
| 极速 | **6 m/s（21.6 km/h）** | 速度上限，不保证每条赛道都能达到 |
| 整车质量 | 3 kg | 教学假设 |
| 轴距 | 0.33 m | 参考实车 |
| 车长 × 车宽 | 0.56 × 0.35 m | 碰撞检测使用的矩形车身 |
| 后轴到车尾 | 0.13 m | 估计；位置参考点为后轴中心 |
| 最大前轮转角 | ±0.379 rad（约 ±21.7°） | 参考实测转向范围 |
| 转角变化速率上限 | 4 rad/s | 舵机响应假设 |
| 速度响应时间常数 | 0.35 s | 速度一阶响应假设 |
| 仿真与控制步长 | 0.02 s（50 Hz） | 仿真时间；电脑运行耗时另计 |

代码用 `accel_g=0.3` 表示整车驱动能力，不再按“仅后轮驱动、后轴静态载荷一半”推导加速度。
制动按四轮制动简化，不再使用仅后轮电机刹车的旧假设。没有独立的侧向0.3 G限制，也没有额外的0.8 G抓地预算。

## 纵横向共用摩擦圆

纵向加速度记为 a_x，侧向加速度记为 a_y：

    a_x² + a_y² ≤ (μg)²
    -μg ≤ a_x ≤ min(accel_g, μ)g

加速能力不足以用满轮胎，不等于纵向轮胎摩擦系数更低。
两个方向只有一个统一的 μ；转弯与加减速共同占用抓地能力。

| 当前纵向动作 | 剩余侧向能力上限 |
|---|---:|
| 匀速，无纵向加速度 | 0.400 G |
| 以0.2 G刹车 | 0.346 G |
| 以0.3 G加速或刹车 | 0.265 G |
| 以0.4 G满刹车 | 0 G |

本实现先按速度指令计算纵向加速度，再用 `sqrt(max((μg)² - a_x², 0))` 限制转弯能力。
因此纵向优先：满刹车时即使打方向，简化模型也不会产生横摆；逐渐松刹才恢复转弯能力。
这是明确的仿真实现规则，不是完整轮胎侧滑、甩尾或ABS模型。控制器应主动安排入弯减速和出弯加速。

## 弯道速度参考

平路、匀速、半径R保持不变时，理论速度上限为 `sqrt(μgR)`：

| 半径 R | 理论最高速度 |
|---|---:|
| 0.83 m | 1.80 m/s |
| 1.0 m | 1.98 m/s |
| 1.5 m | 2.43 m/s |
| 2.0 m | 2.80 m/s |
| 3.0 m | 3.43 m/s |
| 5.0 m | 4.43 m/s |

同时加减速时，将 μg 换成剩余侧向能力。上述值没有预留噪声、跟踪误差的余量，不能直接当作保证可通过的速度。
3 m/s匀速转弯需要至少约2.29 m半径，6 m/s需要至少约9.17 m。
几何最小转弯半径为 `0.33 / tan(0.379)`，约0.83 m；高速时还受抓地限制。

## 直线加速与刹车参考

不计速度响应、以恒定极限加速度计算：0→6 m/s约需 **2.04 s、6.12 m**；6→0 m/s约需 **1.53 s、4.59 m**。
这些是理想化参考。实际仿真速度受0.35 s一阶响应影响，接近目标速度时加减速度减小；目标设为0不代表能在1.53 s内精确归零。

质量用于解释力：总抓地力约11.77 N，最大驱动力约8.83 N。
当前模型直接给定加速度能力，不模拟固定功率/固定扭矩电机；只改质量不会改变运动轨迹。

## 扰动与状态输入

原版A–D使用标称参数和精确状态。扰动版在每圈开始抽取：

- μ上下浮动10%，即0.36–0.44；转弯与制动能力一起变化。独立驱动上限仍为0.3 G。
- 速度响应时间常数、转角速率分别上下浮动20%，整圈保持。
- 地图边界折点抖动±3 cm，整图旋转和平移；控制器拿到扰动后的完整地图。

控制器拿到的车辆参数仍是标称值。每0.02 s提供当前地图绝对坐标等状态，扰动版逐次加入独立高斯观测噪声：位置标准差2 cm、朝向0.01 rad、速度0.02 m/s、横摆角速度0.02 rad/s、纵向加速度0.1 m/s²、前轮转角0.005 rad。
时间不加噪声；不模拟IMU积分漂移或额外通信延迟。判定、计时和轨迹日志始终用真值。

## 判定与适用范围

车辆采用运动学自行车模型、一阶纵向响应、转向速率限制，以及摩擦圆对横摆角速度的限制。
车身越界检查包含矩形与边界线段接触，并按车身运动量进行约1 cm间隔的步内位姿采样；这是离散检测，不是严格连续碰撞检测。

本版本用于已知地图下的规划和控制作业，方法不限。历史0.8 G训练结果，以及“独立侧向0.3 G、纵向0.4 G”的视频和结果，均不代表当前配置的性能；参考模型需要重新评估或训练。
