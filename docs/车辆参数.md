# 车辆参数

仿真里的车参照队里的 1/10 阿克曼实车:**尺寸和转向照实车**,**性能上限按物理估一个合理值**。
这个作业不上实车,所以性能不追求和实车一致,只要物理上说得通。代码在 `fastsim/params.py`。

## 直接给定的值

| 参数 | 值 | 来源 |
|---|---|---|
| 轴距 L | 0.33 m | 实车实测 |
| 车长 × 车宽 | 0.56 × 0.35 m | 实车外形 |
| 后轴到车尾 | 0.13 m | 估计 |
| 前轮最大转角 δ_max | 21.7°(0.379 rad) | 实车实测 |
| 舵机转角速度 | 4.0 rad/s | 假设 |
| 整车质量 m | 3.0 kg | 假设:1/10 底盘 + 电池 + 主控 + 雷达 |
| 摩擦系数 μ | 0.8 | 假设:总抓地预算,控制纵向能力 |
| 独立侧向能力上限 | 0.3 G | 作业难度设定,与纵向上限分开 |
| 后轴载荷比 | 0.5 | 假设:前后重量平均分配 |
| 极速 v_max | 6.0 m/s | 假设 |
| 电机响应时间常数 τ | 0.35 s | 假设 |

## 推导出来的上限

| 量 | 公式 | 值 |
|---|---|---|
| 横向加速度上限 | min(0.3, μ) × g | **2.94 m/s²(0.3 G)** |
| 最大加速度 | μg × 后轴载荷比(后驱,只有后轮出力) | **3.92 m/s²(0.4 G)** |
| 最大减速度 | 同上(电机刹车也只作用在后轮) | **3.92 m/s²(0.4 G)** |
| 最小转弯半径 | L / tan(δ_max) | 0.83 m |
| 最大侧向力 | m × a_lat_max | 8.83 N |
| 最大驱动力 | m × 3.92 | 11.8 N |
| 极速下的驱动功率 | 11.8 N × 6 m/s | 约 71 W |
| 0 → 6 m/s | v / a | 约 1.5 s、4.6 m(不算电机响应) |
| 6 m/s → 0 | v² / 2a | 约 4.6 m |

**质量不影响运动**:加速度都由摩擦限定,a = μmg / m,质量约掉了。质量只在算力和功率时用到。

## 弯道能跑多快

过半径 R 的弯,需要的横向加速度是 v² / R,不能超过 a_lat_max,所以 **v ≤ √(a_lat_max × R)**:

| 弯道半径 R | 最高过弯速度 |
|---|---|
| 0.83 m(打满舵) | 1.56 m/s |
| 1.0 m | 1.72 m/s |
| 1.5 m | 2.10 m/s |
| 2.0 m | 2.43 m/s |
| 2.75 m | 2.84 m/s |

A–D 中心线上最急的弯:A 约 1.3 m,B、D 约 1.5 m;C 左上角的直角处只有约 0.6 m,比车的最小转弯半径还小,沿中心线开是转不过去的,得利用赛道宽度走大一点的弧线。长直道上可以跑到极速。

## 仿真里的车怎么动(`fastsim/car.py`)

每 0.02 秒:

1. **速度**:按 τ 向目标速度靠近,每步变化量不超过加速度或减速度的上限;
2. **转向**:前轮转角以 4 rad/s 的速度转向目标,最多打到 ±21.7°;
3. **转弯**:按自行车模型,横摆角速度 = v·tan(δ) / L;
4. **抓地(摩擦圆)**:加减速会占用一部分抓地力,剩下的才能用于转弯。
   需要的横向加速度超过剩余预算时,车只能转预算允许的那么多,表现为向外推头。
   横向预算 = min(a_lat_max, √((μg)² − accel²))。0.3 G 是独立的保守侧向限制,并不表示 μ=0.3。
   默认纵向最高0.4 G、横向最高0.3 G,组合值仍在μ=0.8的摩擦圆内,两者可以同时达到。
   这是教学模型的能力设定,不代表真实轮胎动力学。
